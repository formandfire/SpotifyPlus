SpotifyPlus

V0.1 mobile skin for the real Spotify Web Player. Spotify still handles playback; SpotifyPlus only makes the interface easier to use on a phone.

1. Use Firefox on Android
The first build uses a userscript manager because Firefox Android supports extensions. The skin itself is plain CSS/JavaScript and is not locked to Firefox.
Get Firefox for Android
2. Install Violentmonkey
Violentmonkey injects the SpotifyPlus skin into the real open.spotify.com page.
Install Violentmonkey
3. Install SpotifyPlus
Tap below in Firefox. Violentmonkey should open an install screen for the userscript.
Install SpotifyPlus V0.1
4. Open Spotify Web
Sign in normally. If Spotify asks for desktop mode, enable it. You should see a small green SP+ button near the upper-right. Tap it to turn the skin on or off.
Open Spotify Web

V0.1 intentionally changes only touch sizing: larger track rows, larger playback buttons, a larger search field and a taller playback bar. It does not bypass ads, skip limits, shuffle rules or any Spotify Free restrictions.
