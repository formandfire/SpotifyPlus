SpotifyPlus v2.0.9

Brave Android build. Uses Brave's native content filtering instead of Tampermonkey, while Spotify remains the actual player.

1. Copy the SP+ v2.0.9 filters
This keeps the v2.0.8 artwork and playlist text sizing, while reducing the playlist row height to remove the extra vertical gaps.
2. Replace the Brave filters
In Brave Android go to Settings → Brave Shields & privacy → Content filtering. Open Create custom filters, replace the old rules with the copied rules, and save.
Open Brave filter settings
3. Test your Profile
Reload Spotify and open Gear → Profile. Artwork and text should look the same as v2.0.8, but the playlist rows should sit closer together.
Open Spotify Web

v2.0.9 still uses no Spotify API, credentials, Tampermonkey, or injected JavaScript. Spotify owns the playlist data and playback; SP+ only changes presentation through Brave filters.
